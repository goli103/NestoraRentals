# Nestora Rentals
**Nestora**: a clickable home-rental app prototype with an AI-style search agent, a  map, school info and star ratings on every listing, and free tour booking.Nestora is a home-rental app prototype built to test how easily renters can find a home and book a tour. The Nestora Agent turns a plain sentence such as “2-bed in the Annex under $3000” into a search, then shows the matching homes on a list and a map. Each listing has a verified badge, a star rating and a school locator with nearby schools and scores. Renters can save homes, message the landlord in a pop-up, and book a free tour in three steps: select a date, confirm details, and confirmation. A My Tours page lets them reschedule or cancel. The prototype includes a hidden facilitator panel for running usability tests with timing, click counts and exportable results.
